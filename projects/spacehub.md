# Plateforme de Location d'Espaces (Space Hub)

![Aperçu de Space Hub](images/spacehub.png)

## Présentation du projet
*Space Hub* est une plateforme web développée en équipe avec le framework PHP Symfony. Son objectif est de mettre en relation des prestataires (offreurs de lieux) et des clients pour l'organisation d'événements. Le projet intègre des fonctionnalités critiques telles qu'un système d'authentification sécurisée, la gestion dynamique d'un catalogue de lieux avec critères de recherche avancés, et un module de réservation lié en temps réel à la disponibilité des espaces.

## Travailler en mode projet 
Ce projet ayant été réalisé en groupe, nous avons dû analyser nos modalités d'organisation et adopter une méthodologie collaborative rigoureuse. Nous avons utilisé le Kanban de GitHub pour le suivi des tâches (colonnes *To Do*, *In Progress*, *Done*). Pour le code, nous avons mis en place un dépôt Git partagé avec gestion des branches : chaque membre développait sa fonctionnalité de son côté avant de soumettre une *Pull Request*, assurant ainsi l'intégrité du code commun avant la fusion.

## Répondre aux demandes d'évolution 
Durant le cycle de vie du projet, nous avons dû traiter des demandes d'ajouts de fonctionnalités spécifiques (maintenance évolutive). Cela a nécessité une analyse approfondie du code existant afin de garantir que les nouvelles briques logicielles s'intègrent parfaitement à l'architecture Symfony. J'ai dû m'assurer que ces ajouts ne créent aucune régression ou bug sur les réservations déjà en cours dans la base de données.
